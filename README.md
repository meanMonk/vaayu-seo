# vaayu-seo

Monorepo generated by `setup-project`. One shared Mongo on the `vaayu_db` network
(local via brew or docker infra, VPS via existing `vaayu_db` Mongo), Nginx routing
generated by `nginx-setup.ts`, and Scalar/OpenAPI docs on every Hono service.

## Layout

```
vaayu-seo/
├── packages/
│   ├── web/        # frontends: app1 (vite), app2 (astro), ...
│   └── backend/    # services: api1 (hono, /docs + /openapi.json), ...
├── scripts/        # local helpers: db-info.sh, hosts-local.sh
├── vps/            # VPS setup + deploy scripts + nginx
├── nginx-setup.ts  # generates per-app nginx site configs
├── docker-compose.yml        # all packages, join vaayu_db (auto-regenerated)
└── docker-compose.infra.yml  # local mongo + minio on vaayu_db (VPS: skip)
```

## Quick start (local)

```bash
bash scripts/db-info.sh                # local brew DB endpoints (mongo :27017)
sudo bash scripts/hosts-local.sh       # one-time: mongo -> 127.0.0.1 for same URIs

# run everything (mongo + minio + apps) with docker:
docker compose -f docker-compose.infra.yml up -d   # infra, once
docker compose up -d --build                       # all apps

# or dev with pnpm (needs local brew mongo):
cd packages/backend/api1 && pnpm install && pnpm dev    # http://localhost:3400/docs
cd packages/web/app1    && pnpm install && pnpm dev     # http://localhost:3001
```

The canonical Mongo URI is the same for brew and docker:

```
MONGODB_URI=mongodb://<user>:<pass>@mongo:27017/<db>?authSource=<db>
```

After `hosts-local.sh`, `mongo` resolves to 127.0.0.1 locally (brew mongod, no auth);
inside docker it resolves to the `mongo` container on `vaayu_db`.

## API docs (Scalar + OpenAPI)

Every generated Hono service:

- `GET /docs`         — interactive Scalar UI
- `GET /openapi.json` — machine-readable spec
- `pnpm openapi`      — writes `openapi.json` to disk

## Screens → app

```bash
screens2app --screens <dir> --app app1          # HTML mockups -> pages + tailwind theme
screens2app --screens <dir> --app app1 --llm    # LLM-enhanced (needs LLM_API_KEY/OPENROUTER_API_KEY)
```

## Nginx

```bash
npx tsx nginx-setup.ts                # regenerates nginx/conf.d/*.conf from .env + compose files
bash vps/nginx/setup-nginx.sh         # on the VPS: installs nginx + certbot, installs configs
```

## Deploy to a VPS

```bash
cp .env.example .env                  # set MONGO_/VA_DOMAIN etc.
# one-time as root:
bash vps/setup.sh                     # docker + vaayu_db network + nginx/certbot
# then:
bash deploy.sh                        # build + run everything on the VPS
bash deploy.sh packages/web/app1      # build + run one app
```

## Add apps / services

```bash
setup-project web=vite                # -> packages/web/app2
setup-project api=hono:invoices       # -> packages/backend/invoices
setup-project api=hono:mongo          # api with Mongo
```
